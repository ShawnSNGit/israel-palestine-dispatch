# Roadmap & Phases

This document outlines the 6-12 month roadmap for scaling this project into an enterprise-grade platform. It complements docs/ARCHITECTURE.md with milestones for each phase.

Phase 0: Foundations (2-4 weeks)
- Repository re-organization, CI, basic services scaffold
- Snapshot & evidence store prototype

Phase 1: Ingestion & Provenance (6-10 weeks)
- Connectors, snapshots in S3, Postgres metadata
- Basic editorial UI

Phase 2: Retrieval & Synthesis (6-10 weeks)
- Vector DB, RAG pipeline
- Initial hedging generator and conflict detector

Phase 3: Compliance & Scale (8-12 weeks)
- Audit signing, legal workflow, security hardening, SLA

Phase 4: Enterprise features (ongoing)
- Multi-region, advanced analytics, partner APIs
