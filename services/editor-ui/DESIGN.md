# Editor UI: design notes

This UI is intended to present data with clarity and empathy. Initial choices:
- Serif typography for long-form reading (legal/press friendly)
- High contrast and generous spacing for readability
- Inline hedging suggestions and clear provenance links

Future work:
- Add Storybook stories for components
- Add Cypress E2E tests for key flows
- Add PDF/print export and accessible keyboard navigation
